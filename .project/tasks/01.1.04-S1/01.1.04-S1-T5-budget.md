# 01.1.04-S1-T5 — Measure organization branding at target volume

## Task understanding

Measure the Workspace organization-branding list query using 50 organizations and 200 reads. Record the p95 against the story's 700 ms first-page target, confirm and name the index used by the query, and retain a dated measurement that can serve as a regression baseline. T3's 342 ms number is a separate browser measurement against the isolated web mock; it is not evidence of MongoDB query performance.

## Implementation

- Added a workspace-list covering index with the query equality fields first: `workspaceId`, `deletedAt`, then the projected organization branding fields.
- Kept T1's single-organization scoped index unchanged; it has a different query shape.
- Added `servers/api/scripts/seed.ts`. It creates a uniquely named temporary MongoDB collection, seeds 50 organizations, creates the declared indexes, confirms the list query's explain plan uses the named list index, performs 200 measured reads, calculates nearest-rank p95, compares it with 700 ms, and drops its temporary collection in `finally`.
- No records are added to or removed from the application `workspaces` collection.
- The product quality-attribute table is `.project/quality-attributes.md`; it records the 50-organization / 200-open / 700 ms target and links both the web and database evidence.

## Validation and evidence

- Automated cases cover nearest-rank p95 calculation and acceptance of only the named index in both the winning and executed explain plans.
- Live seeded MongoDB measurement on 2026-10-02: **67.21 ms p95** across 200 reads of 50 synthetic workspace organizations, against the 700 ms budget. The winning and executed plans used `workspace_organization_branding_list_covering`.
- The benchmark created and dropped a uniquely named temporary collection; it did not change application workspace records. The reproducible command is `pnpm --dir servers/api run test:branding-budget` with the configured `MONGODB_URI`. It prints a dated JSON result and exits non-zero if the p95 exceeds budget or the named index is not used.
- Full API suite: **24 passed**. API typecheck and lint passed.
- The existing T3 production-build browser measurement was **342 ms p95 over 200 opens** against the mock-backed 50-organization fixture. This remains supporting UI evidence and is not substituted for the seeded Mongo query result.
