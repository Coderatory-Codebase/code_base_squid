# T1 prerequisite support — Workspace branding persistence

This support file is separate from the T1 gateway implementation so the Workspace owner can replace it when the upstream schema is merged.

## Added for T1

- `servers/api/integrations/mongodb/workspace-branding.model.ts` defines a provisional Mongoose Workspace branding model and a compound covering index named `workspace_organization_branding_covering`.
- MongoDB integration exports expose the model and query adapter; the feature gateway still receives the reader contract through the Workspace feature boundary.
- The compound index covers the scope filters and selected branding fields. It has been provisioned in the configured development database and verified by a live explain plan.

## Deliberately not added

No automatic TTL purge was introduced. A TTL index permanently deletes matching documents; that behavior is outside T1’s Done When. No fixture records were written to the configured database.

To replace this prerequisite later, use the merged Workspace module’s owning schema and index. Keep the T1 gateway and isolation tests.
