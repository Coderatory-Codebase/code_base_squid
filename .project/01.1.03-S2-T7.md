## Accessibility changes and checks

- Added a 2 px focus ring and offset to all settings fields and action buttons. Light mode
  uses the shared ring/background tokens; dark mode uses a lighter ring and dark offset.
- The existing polite status region announces save progress and the result. The test now
  verifies that a failed retry rolls the optimistic summary back to the last saved values,
  announces the failure, and leaves the user's unsaved draft available.
- Conflict and failure states have text and alert semantics; validation uses a visible
  label and the input's required semantics. Status is not conveyed by color alone.
- Focus order, native focusability, theme-specific focus classes, Conflict content, live
  status, and rollback were checked in the focused jsdom test.
