# 01.1.03-S2-T2 — Organization setting domain rule

## Implementation

- Added the pure Workspace domain resolver in
  `servers/api/features/workspace/domain/organization-setting.ts`.
- The resolver returns `Result<OrganizationSetting, OrganizationSettingError>`, resolves
  all four defaults and validates organization overrides without throwing.
- Replaced the duplicate value/default validation in
  `db/organization-setting.gateway.ts` with calls to the domain rule. The gateway keeps
  logging read failures and translates invalid persisted data at the infrastructure edge.
- Added six focused unit cases: defaults, valid overrides, and invalid time zone, week
  start, date format, and workspace-setup rule values.
